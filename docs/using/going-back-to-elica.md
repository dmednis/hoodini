# Go back to the Elica app

1. Stop Hoodini, then hold T6 on the hood for six seconds to reset its Wi-Fi configuration.
2. Follow the Elica Connect app's normal Wi-Fi setup to add the hood back to the official service.
3. Check that the app shows the hood. If it does not, retry the app's setup steps and consult its support documentation.

This is a manual Wi-Fi reset, not a Hoodini command. Previously discovered Home Assistant MQTT entities may remain until removed from the broker or HA. See [known limitations](../reference/known-limitations.md).
